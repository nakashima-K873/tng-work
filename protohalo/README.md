# Protohalo analysis

IllustrisTNG300-1 の高赤方偏移ハローと z=0 descendant の解析をまとめています。

| ディレクトリ | 内容 |
|---|---|
| [notebooks/](notebooks/README.md) | 実行ノートブック、解析の順序、入出力と再利用データの案内 |
| `data/` | 保存済みのハロー対応表、環境カタログ、頑健性確認の要約、z≈10の比較出力 |
| [analysis_summary/](analysis_summary/tng300_analysis_summary_ja.md) | 日本語の解析まとめ、COLIBREとの比較、抽出図、z≈8の条件付きPDF出力 |
| `cache/` | 再計算を減らす粒子・SubLinkのキャッシュ（Git管理対象外） |

まず [主要結果の要約ノートブック](notebooks/tng300_main_results_summary.ipynb) を開き、個別解析は [ノートブック索引](notebooks/README.md) から参照してください。保存済みの解析データと図は保持しています。
